It is thorough but not independent, and it is not a certification, a regulatory approval or a substitute for review by an independent statistician. It is intended to make that independent review faster and better targeted.

1. Summary

The core algorithms are correctly implemented: every one either matches an established implementation to within numerical tolerance or reaches an equal or better optimum. The defects found lay mainly in the logic around the algorithms (how data are read, how levels are ordered, which values are described, what a verdict claims) and in a few explanations shown to the user. Five were judged major, because they could change a result or how it is interpreted. All have been corrected.

2. Scope and method

  • Mathematical review. Each routine was read against its published definition: k-means and k-means++, PAM (BUILD and SWAP), Ward and other linkages by the nearest-neighbour chain, Gaussian mixtures (EM), latent class and latent profile analysis, Gower dissimilarity with balanced weights, silhouette, Calinski–Harabasz, Davies–Bouldin, adjusted Rand index, PCA and FAMD, gap statistic, bootstrap stability, both tests of "no real sub-groups", chi-square, Kruskal–Wallis, Benjamini–Hochberg, Cramér's V, ε², the classification tree and Cohen's κ.
  • Independent recomputation. Results were compared with scikit-learn, SciPy, NumPy, umap-learn and the R packages cluster, poLCA, mclust, FactoMineR and VarSelLCM. Components with no external comparison were given one (section 3).
  • Logic and message review. Every verdict, suggestion, warning and explanation was traced to the quantity it reports, to check that each number shown is the number computed and that each claim is supported.
  • Adversarial testing. 47 hostile inputs to the engines (identical patients, constant or empty columns, perfectly correlated variables, a single cluster, more clusters than distinct values, extreme magnitudes) and 13 file formats (semicolon and tab separators, Windows line endings, quoted commas and line breaks, byte-order marks, duplicate or empty headers, ragged rows).
  • Scale testing. A simulated file of 30,000 records taken through every step, with the longest interruption of the page measured in each.

4. Appraisal of the test of "no real sub-groups"

This test carries much of the weight of the verdict, so it was examined beyond implementation correctness.

  • Gaussian reference. Reference datasets are standard normal samples whitened on their own principal axes and given the data's sample mean, axes and variances. Under a single Gaussian population the observed data, whitened the same way, have the same conditional distribution given the sample mean and covariance, so the Monte Carlo p-value is exact conditionally on those statistics. Simulations agree (3.3% false positives at the 5% level).
  • Copula reference. Used whenever a clustering variable is skewed or not numerical. It maps a latent Gaussian population onto each variable's observed distribution, with latent correlations adjusted (NORTA) until the observed Pearson correlations are reproduced; categories with several levels come from a single latent cut. No false positives in 100 simulated mixed datasets; detection 30 of 30 at a separation of 3 SD and 20 of 30 at 2.2 SD, so the test is conservative. It now reports how closely the correlations were reproduced (0.006 to 0.037 on the demonstration data).
  • What the statistic measures. The statistic is the R² of a k-means partition into k groups, whatever method formed the clusters. The test therefore asks whether the data contain separable structure, not whether the chosen partition is optimal. The interface wording has been corrected to say so (F-6).
  • Known limitation. Both references describe a single population without curvature. A curved or branching continuum can pass both tests; every positive verdict says so and points to the maps and dimensions for checking.

5. Robustness and responsiveness

Of 47 hostile engine inputs, all were handled. Five returned a non-finite value: two were defects (F-11, F-12); three are mathematically correct and are shown as "–" (an infinite Calinski–Harabasz index for a perfect fit, coincident centres in Davies–Bouldin, and an adjusted Rand index for one patient). All 13 file formats were read correctly; one exposed a defect in number recognition (F-5).

6. Findings and corrections

Each finding gives the defect, its effect, the correction and the automated test that now guards against its return.

Major

F-1

A positive verdict could claim a test that had not been run

Major
Defect
When the test of "no real sub-groups" could not run (missing values kept as "recorded values only"), stability alone made the verdict positive, with the text "more separated than a single population".
Effect
Overstated evidence: stable clusters can arise from a continuum.
Correction
Without the test, the verdict is at best "mixed" and explains how to run the test.
Test
Browser check on the latent-class demonstration with missing values kept.
F-2

Filled-in values were described as if recorded

Major
Defect
With "fill missing values", cluster profiles, class descriptions, the decision tree, colouring of maps by a variable and the record table used the medians and modes filled in for clustering. Missing counts showed zero.
Effect
Means pulled towards the median, spreads understated, missingness hidden; the tree learned thresholds from imputed values.
Correction
All description uses the values as recorded; the clustering itself still uses the filled data, as chosen.
Test
Browser check on the 8,000-referral demonstration with filled values: the profile reports the 271 recorded missing values.
F-3

Text grades were ordered alphabetically

Major
Defect
Grades written as words were ordered alphabetically, so "Low, Medium, High" became High < Low < Medium.
Effect
Wrong ordinal distances in Gower dissimilarity, wrong tree thresholds and a wrong profile order.
Correction
Clinical word order is used (none < mild < moderate < severe, low < medium < high). The order is shown in step 2 and can be edited there, with a caution when it was not recognised. The data checks use the same order.
Test
Browser checks of recognised orders and of a user-corrected order.
F-4

"None" was treated as a missing value

Major
Defect
The text "None" was read as missing.
Effect
Genuine answers ("no symptoms", "no comorbidity") were dropped or imputed over; 20 of 80 grades in the test file.
Correction
"None" is a value. The generated R script follows the same rule.
Test
Browser check: zero missing values in the graded test file.
F-5

European decimal commas made numeric variables disappear

Major
Defect
In semicolon-separated files with decimal commas ("67,5"), numeric columns were read as text categories and, being nearly all distinct, set to "Ignore".
Effect
Key variables silently left out of the analysis.
Correction
Columns written consistently with decimal commas are read as numbers and the conversion is reported. In comma-separated files a comma followed by exactly three digits is left alone, since it may be a thousands separator.
Test
Browser check with a European-format file.

Moderate
Defect
The text said the suggestion "follows Tibshirani's rule"; the rule is used only to warn when it chooses one cluster.

F-9

BIC guidance misstated the conventional scale

Moderate
Defect
"Differences under about 10 are not decisive."
Correction
Raftery (1995): 10 or more very strong, 2 to 6 positive, under 2 negligible.
F-10

The page froze for up to 15 seconds on large files

Moderate
Defect
Local outlier factor and map training ran in single blocks; explanations of unusual records recounted each category over all records; the data-check map drew every record; the copula simulation grew without bound.
Correction
Generators with progress; counts computed once; the map shows every flagged record plus a sample; the simulation is capped at 200,000 draws (correlation standard error about 0.002). See section 5.

7. Residual limitations and recommendations

The following are not defects but should be considered by independent reviewers.

  • Clinical validation. The software has not been applied to real cohorts. A protocol is provided in docs/validation_protocol.md: pre-specified variables, outcomes and criteria; a derivation and an independent validation cohort; transportability and reproducibility checks.
  • Independent statistical review. Suggested focus: calibration and power of the copula test under misspecified margins; the conventional thresholds (stability 0.75, silhouette bands) and the rule that suggests a number of clusters; local independence in latent class analysis when clustering variables are related; and multiple imputation followed by consensus clustering.
  • Imputation of text grades. Multiple imputation treats grades written as words as unordered categories (predictive mean matching on indicators). This is valid but ignores their order.
  • Conventions. The thresholds used for stability, separation and the "poorly represented" new-patient rule (95th centile of the original patients' distances) are conventions, stated as such in the interface.
  • Shared code. The data engine is shared with a companion prediction application and contains routines this application never calls (for example SMOTE-NC and grouped train–test splitting). They were not audited here.
  • Regulatory position. The software is presented for research and education and is not a medical device. Use for diagnosis or decisions about individual patients would require assessment under the applicable medical device regulations, for example the MHRA's guidance on software as a medical device in the United Kingdom.
